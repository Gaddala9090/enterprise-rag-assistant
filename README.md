# Enterprise RAG Assistant

A Retrieval-Augmented Generation (RAG) system that answers questions over a set of documents using an LLM + vector search — built to mirror how enterprise document Q&A systems work in production.

## Problem
Employees waste hours digging through scattered PDFs, wikis, and policy docs to find answers. This system retrieves the right passages and generates a grounded answer with citations, instead of a plain keyword search.
